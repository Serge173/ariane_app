1. Vue d'ensemble de l'application

Application full-stack unique : site vitrine premium, parcours de réservation et de paiement, boutique en ligne, espace client, blog, newsletter et back-office administrateur complet. Conçue mobile-first, avec une identité visuelle sobre (inspiration luxe / Polène).

Parcours métier : Prospect → Orientation / découverte → Prestation ou produit → Rendez-vous → Paiement (CinetPay) → Coaching & questionnaires → Suivi (Mon espace) → Fidélisation (newsletter, blog).

Modules fonctionnels principaux

Module Rôle
Site public Accueil, offres, orientation, réservation, panier, checkout, blog, FAQ, contact, WhatsApp
Parcours découverte Formulaire configurable (admin) + créneaux RDV, stocké en base (ContactRequest + metadata)
E-commerce Produits, variantes (taille/couleur), stock, codes promo, commandes, expédition (fulfillment)
Mon espace client Profil, commandes, RDV, documents, questionnaires
Admin Contenu, offres, boutique, commandes, RDV, blog, newsletter, paiements, utilisateurs, analytics
Newsletter Inscriptions, modèle d'email éditable, envoi manuel / auto à la publication blog, webhook externe

2. Architecture logicielle

Next.js 15 avec App Router (src/app/) : pages React côté serveur et client, Route Handlers pour les API REST (src/app/api/). Pas de backend séparé : logique métier dans src/lib/, accès données via Prisma.

Navigateur (client) │ ▼ Vercel Edge / Node (Next.js 15) ├── React 19 (RSC + Client Components) ├── API Routes (auth, paiements, admin, webhooks) ├── NextAuth (sessions) └── Prisma Client │ ▼ PostgreSQL (Neon) + Vercel Blob (médias prod) · public/uploads (local)

Patterns utilisés

  • Server Components par défaut ; composants interactifs en "use client"
  • Zustand pour l'état panier côté navigateur
  • React Hook Form + Zod pour formulaires et validation
  • Settings JSON en base (SiteContent) pour contenus éditables (hero, parcours découverte, newsletter)
  • Webhooks : CinetPay (paiement), publication newsletter (Zapier/Make possible)

6. Paiements

Intégration CinetPay (Côte d'Ivoire et zone Mobile Money) : Orange, MTN, Moov, Wave, carte bancaire — canaux configurables en admin (PaymentMethodConfig).

  • Création de transaction côté serveur (src/lib/payments/cinetpay.ts)
  • Webhook de notification : /api/payments/webhook
  • Statuts commande / paiement synchronisés en base (enums Prisma)

7. Emails & newsletter

  • Resend — envoi transactionnel et campagnes (src/lib/email.ts)
  • Modèle newsletter éditable en admin, variables dynamiques (contenu publication, liens réseaux)
  • Envoi automatique à la publication d'un article blog (si activé)
  • Webhook /api/webhooks/newsletter-publication pour automatisation externe
