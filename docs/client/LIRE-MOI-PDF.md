# Documents client (PDF)

Deux fichiers HTML prêts à partager ou imprimer en PDF.

**Développement de la plateforme : KEAYENI SERGE PACOME**

| Fichier | Usage |
|---------|--------|
| `Fiche-client-Ariane-DAGO-1page.pdf` | **Fiche 1 page (PDF prêt à envoyer)** |
| `Presentation-client-Ariane-DAGO.pdf` | **Présentation complète (PDF, ~6 pages A4)** |
| `Presentation-technique-stack-Ariane-DAGO.pdf` | **Application + stack technique dev (~8 pages)** |
| `fiche-une-page.html` | Source de la fiche — modifier puis réimprimer en PDF |
| `presentation-complete.html` | Source de la présentation complète |
| `presentation-technique-stack.html` | Source du dossier technique (technologies, architecture) |

## Générer un PDF (Windows / Mac)

1. Double-cliquez le fichier `.html` (s'ouvre dans le navigateur).
2. Cliquez **« Enregistrer en PDF (Imprimer) »** ou `Ctrl+P` / `Cmd+P`.
3. Imprimante : **Enregistrer au format PDF** (ou Microsoft Print to PDF).
4. Format : **A4**, marges par défaut.
5. Enregistrez sous un nom du type `Fiche-client-Ariane-DAGO.pdf`.

## Personnaliser l'URL du site

Dans `fiche-une-page.html`, remplacez la ligne « Votre site Ariane DAGO » par votre domaine (ex. `https://ariane-app.vercel.app`).

## Envoi aux clientes

- Joindre le PDF à un email de bienvenue après RDV.
- Imprimer la fiche une page pour un dossier papier.
- Utiliser la présentation complète pour un atelier ou une première séance.
